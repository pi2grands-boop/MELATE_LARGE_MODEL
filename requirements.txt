# Máquina Melate — dependencias
#
# Restricciones, no versiones exactas, salvo las tres que hablan con el exterior o con el
# navegador (scrapling, streamlit, duckdb), que van fijadas. El fijado exacto de todo vive en
# entorno/pip-freeze-<fecha>.txt; el de 2026-10-02 es el que reproduce la línea base.
# Instalar con:  python -m pip install -r requirements.txt
#
# Ninguna de estas compila: todas tienen wheel para cp313-win_amd64 o son
# Python puro. Por eso este proyecto no necesita Docker.

numpy>=2.3,<3

# <3 a propósito: pandas 3.0 cambia la propagación de df.attrs, que
# baseline_auditoria.py usa (línea 68, leída en la 279). Migrar a pandas 3
# es un cambio aparte, con su propio documento.
pandas>=2.3,<3

scipy>=1.14,<2

# La dependencia más sensible del proyecto: el mismo random_state puede dar
# otro árbol en otra versión. Ver el documento de Reproducibilidad.
scikit-learn>=1.5,<2

requests>=2.32,<3
pytest>=8,<10

# --- Fase 3: las tablas de ganadores de melate-e.com ---
#
# Fijada exacta, no por rango: es la unica dependencia que habla con un sitio
# de terceros, y un cambio de version puede cambiar las cabeceras que salen o
# el comportamiento del parser sin avisar. El trato con ese sitio esta escrito
# en Documentos_Contexto/Fases/2026-10-03_popularidad/Decisiones/ y se comprueba
# con tests; una actualizacion de esta linea obliga a volver a correrlos.
#
# El extra [fetchers] arrastra playwright y patchright —dos pilas completas de
# automatizacion de navegador— mas browserforge y apify-fingerprint-datapoints,
# que existen para falsificar huellas. NADA de eso se usa: popularity.py solo
# hace GET con Fetcher sobre HTML estatico, y StealthyFetcher y DynamicFetcher
# estan prohibidos por el CLAUDE.md. Los navegadores no se descargan (haria
# falta `playwright install`, que no se ejecuta). Queda anotado como lo que es:
# un coste de la libreria elegida, no un accidente.
scrapling[fetchers]==0.4.15

# --- Fase 4: la app local y su base ---
#
# Fijadas exactas. streamlit levanta un servidor web; su dirección de escucha, su telemetría y su
# comprobación de origen se revisaron leyendo el código de ESTA versión (1.65 ya no usa Tornado
# sino Starlette y uvicorn), y una actualización obliga a revisarlas otra vez: ver
# Documentos_Contexto/Fases/2026-10-04_app-local/. Trae 21 dependencias, todas con wheel.
# El lanzador (src/melate/app.py) sustituye además una función interna suya,
# net_util.get_external_ip; tests/test_lanzador.py falla a la vista si una versión nueva la
# renombra o la importa de otra forma.
#
# streamlit admite pandas<4: instalar SIEMPRE con este fichero, que mantiene pandas<3 (arriba).
# Un `pip install --upgrade streamlit` suelto podría subir pandas a la 3 y romper el oráculo.
#
# duckdb guarda melate.duckdb, que no se publica y se reconstruye con `python -m melate.almacen`.
streamlit==1.65.0
duckdb==1.5.6
